# LLM Docs

This folder is optimized for AI assistants and code agents that need compact,
task-oriented context without reading the full repository first.

## Read Order

1. [project-context.md](project-context.md): mission, status, invariants, and
   current risk boundaries.
2. [code-map.md](code-map.md): where to look for each kind of task.
3. [change-playbook.md](change-playbook.md): how to make and verify changes
   without breaking parity or user work.

These files are guidance, not a replacement for source. When they conflict with
code, tests, or `config.example.toml`, update the docs after following the code.
